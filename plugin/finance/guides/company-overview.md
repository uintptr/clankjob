# Company overview

Adapted from `commands/company.md`. A concise overview of one company.

## Data

Call `stock_data` for the ticker with `data` = `info`, `fast-info`, `recommendations`,
`price-targets`, and `news` (`count` 5). Use only what these return; leave a cell as `n/a`
rather than filling it from memory.

## Output

Write the overview as the answer (the `complete` summary, or a message to the owner).
