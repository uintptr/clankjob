# Ratio analysis

Adapted from `commands/ratios.md`. Key financial ratios of one company.

## Data

Call `stock_data` for the ticker with `data` = `info`, `fast-info`, `income` (`freq` =
`yearly` and `trailing`), `balance` and `cashflow` (`freq` = `yearly`). Compute the ratios
`info` lacks from the statements, and say which ones you computed.

## Output

Write the analysis as the answer (the `complete` summary, or a message to the owner).
